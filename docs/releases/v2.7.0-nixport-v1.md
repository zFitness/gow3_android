# God of War III Remastered · SpartanPort nixport 2.7.0 (arm64)

> **This release matches the PC build 2.7.0 feature for feature**: the game itself, the in-game
> menus and the launcher carry the same features as PC 2.7.0 (Automatic QTE, the enemy health
> bar, multipliers, Exit to Desktop, local trophies, shader-cache reuse, ultrawide, and the
> rest). On top of that it adds the ARM64 Android work: distribution as a nixport Port
> package, an on-screen button layout laid out for a landscape phone, and importing saves
> from a zip.

## What this package is

| | |
|---|---|
| Asset | `SpartanPort.nixport.2.7.0.zip` (92.3 MB, SHA-256 `c1608ab7…23261e`) |
| Host | **nixport** (from <https://github.com/zFitness/nixport/releases>; no root needed) |
| Architecture | **arm64 (aarch64) Android** — the phone has no x86-64, so the game's guest code runs on **FEXCore**; the graphics still go through the shadPS4 core to Vulkan (Turnip on Android) |
| GPU | **Qualcomm (Adreno)** with Turnip, Vulkan 1.3 |
| Version | **2.7.0**, the same version number as the PC build |
| You need | your own game dump (CUSA01740 and friends: `eboot.bin`, `sce_module`, `sce_sys`) |

## Install

1. **Install the nixport host first**: download the APK from the
   [releases page](https://github.com/zFitness/nixport/releases) and install it on the phone
   (the first start unpacks the rootfs, which takes a while).
2. Copy `SpartanPort.nixport.2.7.0.zip` to the phone (`/sdcard/Download/`).
3. In nixport: **Library → the “+” at the top right** → pick that zip → “Import complete:
   SpartanPort”.
4. Open the **SpartanPort launcher** → choose the game folder → save → play.

> An existing install is **updated in place** (the package id is `spartanport`). The saves
> live in `files/imports/spartanport/home/gport/user/savedata`; back them up before
> re-importing.

## Features (aligned with PC 2.7.0)

### In the game

- **Automatic QTE** — the timed, repeat, charged and circle prompts answer themselves; no
  button mashing.
- **Enemy health bar** — a bar over each enemy, toggled in the game's own Display menu.
- **Cheats** — infinite health, infinite magic, infinite item meter, infinite Rage of Sparta,
  max red orbs, unlock Very Hard, infinite double jumps, Automatic QTE.
- **Multipliers** — red / green (health) / blue (magic) / gold (Rage of Sparta) orbs and
  damage dealt and taken, 0.1x–100x, with *Reset all to 1x*.
- **Exit to Desktop** — from the pause menu, without killing the process.
- **Local trophies** — the in-game list (**F8** or **R3+R2**) and a Trophies page in the
  launcher; the icons come from your own game files.
- **Saves** — the save list (up to 32 entries), autosave, a confirmation before overwriting a
  slot, a backup before every start and a one-click restore in the launcher.
- **Native in-game menus** — Cheats and Multipliers pages in the game's own Options.
- **In-game button icons** — shown as keyboard, Xbox or Nintendo glyphs.

### Graphics

- **Render resolution** — 480p / 720p / 900p / 1440p / 1800p / 4K, plus a few sizes that
  are still marked beta.
- **Ultrawide (beta)** — 21:9, 32:9 and 16:10: a wider field of view instead of a zoomed-in
  picture, with 16:9 borders kept for the cutscenes.
- **Engine frame rate** — 60 / 100 / 120 / 144 / 180 / 240, switched live with **F9**.
- **Patches** — the texture fix, skip videos with the X button, 120 FPS and the other
  community patches.
- **Shader cache** — compiled in the background and **reused on the next start** (on the PC
  build the second start compiles 6 shaders instead of 623); the launcher can delete it.
- **Performance overlay** — FPS, frametime, upscaler, GPU name and use, CPU, RAM and VRAM,
  each one optional.

### Audio, input and launcher

- Music, voices and sound effects (ATRAC9 and MP3); controllers (SDL3) and the keyboard at
  the same time.
- The launcher has five pages — **Home / Graphics / Performance / Game / Advanced** — in
  Chinese (also English, Spanish, Portuguese and more).
- A failed memory reservation now says so and shows the log, instead of a black screen.

## ARM64 Android specific

- **An on-screen button layout for a landscape phone** (17 controls): △○×□ under the right
  thumb, the shoulders under the index fingers, the d-pad for the four main weapons. The
  sticks are fixed, so the hit boxes never overlap.
- **The port's own entries sit on keyboard keys** — menu `Insert`, trophies `F8`, frame
  rate `F9`. The game never receives those keys, so they cannot leak into a fight.
- **Rage of Sparta on one button** (`rage_one_input`; the port expands it to L3+R3).
- **Import saves from a zip in the launcher**: the package holds
  `savedata/1/<title id>/<slot>/SAVEDATA`, it replaces that title's saves, the current ones
  are backed up first, and a different title id is reported before the import.
- **No root required.**

## What differs from the PC build

Steam integration, Discord Rich Presence, desktop shortcuts, Alt+Tab fullscreen, monitor
selection and the Windows audio fallback are desktop features. The touchpad and photo mode
do **not** show on screen (Android has no touchpad). Frame rates are limited by the phone's
GPU (about 60 FPS at 540p in direct mode on the test tablet).

## Known issues

- **Only Qualcomm GPUs are supported for now** (Adreno with Turnip). Other GPU vendors
  (MediaTek, ARM Mali, Google Tensor, …) are unverified: the graphics stack needs an
  Android Vulkan 1.3 driver and the Turnip compatibility layer.
- High frame rates can still block some traversal and QTE sequences. Switch to 60 FPS with
  F9 for that part.
- The trophies are local: PlayStation unlocks are not imported.
- 8K and the other beta resolutions need more memory and VRAM.
- Do not share one shader cache with an older build (it writes the old numbering). If it
  happens, delete `user/cache/<title id>/disk_shaders.bin` to force a rebuild.
- Autosave capacity is unchanged, and the save previews are not verified on every region
  and update.
- The native menus need a recognized game script; other regions or updates may need more
  work.

## Validation

- On a real tablet (1904×3040, Adreno 830 with Turnip): the game starts, the cutscenes
  play (H.264), the game runs at 60 FPS, saves are written and read back, the trophy list
  and both the port menu and the in-game menu open.
- Source: the `arm` branch at `0c2277d4`
  ([zFitness/gow3_android](https://github.com/zFitness/gow3_android/tree/arm)).

# 战神3限定版 · SpartanPort nixport 2.7.0（arm64）

> **本版本的移植功能与 PC 端 2.7.0 完全对齐**：游戏本体、游戏内菜单、启动器的功能都跟上了 PC 版
> 2.7.0（自动完成 QTE、敌血条、倍率、Exit to Desktop、本地奖杯、着色器缓存复用、超宽屏等）。
> 在此之上，额外做了 ARM64 Android 专属的适配：nixport Port 包分发、按横屏握持重排的屏上虚拟
> 按键、从 zip 导入存档。

## 这个包是什么

| | |
|---|---|
| 资产 | `SpartanPort.nixport.2.7.0.zip`（92.3 MB，SHA-256 `c1608ab7…23261e`） |
| 宿主 | **nixport**（从 <https://github.com/zFitness/nixport/releases> 装；不需要 root） |
| 架构 | **arm64（aarch64）Android** —— 手机上没有 x86-64，游戏 guest 代码跑在 **FEXCore** 上；图形仍是 shadPS4 → Vulkan（Android 侧用 Turnip） |
| GPU | **高通（Adreno）**，配 Turnip，Vulkan 1.3 |
| 版本 | **2.7.0**，与 PC 端同版本号 |
| 需要 | 你自己的游戏 dump（CUSA01740 等，`eboot.bin` / `sce_module` / `sce_sys` 齐全） |

## 安装

1. **先装宿主 nixport**：从[发布页](https://github.com/zFitness/nixport/releases)下载 APK 装到手机
   （第一次启动会解包 rootfs，等一会儿）。
2. 把 `SpartanPort.nixport.2.7.0.zip` 传到手机（`/sdcard/Download/`）。
3. nixport → **库 → 右上「+」** → 选这个 zip → 提示「导入完成：SpartanPort」。
4. 进 **SpartanPort 启动器** → 选游戏目录 → 保存 → 开始游戏。

> 已经有这个 Port 的话是**原地更新**（包的 id 就是 `spartanport`）。存档在
> `files/imports/spartanport/home/gport/user/savedata`，重新导入前先备份。

## 功能（与 PC 端 2.7.0 对齐）

### 游戏内

- **自动完成 QTE** —— timed / repeat / charged / circle 四类提示自动应答，不用手按。
- **敌血条** —— 敌人的血量条，在游戏内显示菜单里开关。
- **金手指** —— 无限生命、无限魔力、无限道具能量、无限斯巴达之怒、最大红魂、解锁极难模式、
  无限空中跳跃、自动完成 QTE。
- **倍率** —— 红球 / 绿球（生命）/ 蓝球（魔力）/ 金球（斯巴达之怒）与造成、承受伤害，0.1x–100x，
  一键「全部恢复为 1 倍」。
- **Exit to Desktop** —— 暂停菜单里退出到桌面（不用杀进程）。
- **本地奖杯** —— 游戏内列表（**F8** 或 **R3+R2**），启动器有奖杯页；图标取自你自己的游戏文件。
- **存档** —— 存档列表（最多 32 条）、自动存档、覆盖前的确认、启动前自动备份、启动器里一键恢复备份。
- **游戏内原生菜单** —— 游戏选项里就有 Cheats 与 Multipliers 页。
- **游戏内按键图标** —— 可换成键盘 / Xbox / Nintendo 样式。

### 画面

- **渲染分辨率** 480p / 720p / 900p / 1440p / 1800p / 4K（另有若干标注 beta 的分辨率）。
- **超宽屏** 21:9 / 32:9 / 16:10 —— 更宽的视野而不是放大画面，过场保持 16:9。
- **引擎帧率** 60 / 100 / 120 / 144 / 180 / 240，**F9** 现场切换。
- **补丁**：纹理修复、跳过过场动画（X 键）、120 FPS 等社区补丁。
- **着色器缓存**：后台编译，**第二次启动复用上次的结果**（PC 端实测：二次启动从 623 次编译降到
  6 次），可在启动器里删缓存。
- **性能叠加层**：FPS、帧时间、放大器、GPU 名称与占用、CPU、内存、显存，逐项可开关。

### 音频 / 输入 / 启动器

- 音乐、语音、音效（ATRAC9 与 MP3）；手柄（SDL3）与键盘同时可用。
- 启动器五页：**主页 / 图形 / 性能 / 游戏 / 进阶**，中文界面（另有英语、西语、葡语等）。
- 内存不足时给提示与日志，而不是黑屏。

## ARM64 Android 专属

- **屏上虚拟按键布局**（17 个控件，按横屏握持重排）：△○×□ 在右拇指一掌之内、肩键给食指、方向键
  切四把主武器。摇杆固定不浮动，命中框互不重叠。
- **端口自己的入口用键盘键** —— 端口菜单 `Insert`、奖杯 `F8`、帧率 `F9`：这些键游戏永远收不到，
  不会误触。
- **「斯巴达之怒」一个键触发**（`rage_one_input`，端口内部展开成 L3+R3）。
- **启动器里从 zip 导入存档**：压缩包放 `savedata/1/<title id>/<slot>/SAVEDATA`，整目录替换该
  title，导入前自动备份，title id 不一致会先提示。
- **不需要 root**。

## 与 PC 端的差别（桌面专属功能在安卓上没有）

Steam 集成、Discord 状态、桌面快捷方式、Alt+Tab 全屏、显示器选择、Windows 音频回退 —— 这些是桌面
专属；触摸板与拍照模式**不上屏**（安卓没有触摸板）。帧率受手机 GPU 限制（实测 540p 直通约 60 fps）。

## 已知问题

- **目前只支持高通 GPU**（Adreno 配 Turnip）。其它 GPU 厂商（联发科、ARM Mali、Google Tensor 等）
  未验证：图形栈需要 Android 的 Vulkan 1.3 驱动与 Turnip 兼容层。
- 高帧率下部分跑酷与 QTE 序列可能卡住 ⇒ 那段用 **F9** 切回 60。
- 奖杯是**本地的**：不导入 PlayStation 的解锁。
- 8K 与其他 beta 分辨率需要更多内存与显存。
- 不要和旧版本共用着色器缓存（旧编号会写坏）⇒ 删掉 `user/cache/<title id>/disk_shaders.bin` 强制重建。
- 自动存档容量未变；存档预览未在所有区域/更新版本上验证。
- 原生菜单需要能识别的游戏脚本，其他区域/版本可能还要打磨。

## 验证

- 平板（1904×3040，Adreno 830 + Turnip）真机：进游戏、过场（H.264）、游戏画面 60 fps、存档读写、
  奖杯列表、端口菜单与游戏内菜单。
- 源码：`arm` 分支 `0c2277d4`
  （[zFitness/gow3_android](https://github.com/zFitness/gow3_android/tree/arm)）。
