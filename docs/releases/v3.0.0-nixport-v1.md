# SpartanPort 3.0.0 — ARM64 / nixport (v3.0.0-nixport-v1)

## English

**This release brings the ARM64 port to feature parity with the PC version: what upstream 3.0.0
ships is in the package, and the few pieces that are not are listed below with the reason.**

### In the package

- **Upstream 3.0.0 merged in full** (489 commits, `windows-v3.0.0` → `a2299cd`): the runtime, the
  graphics stack, the patch set and the launcher text.
- **Patch set**: upstream's explicit-size resolution patches (1280x800 … 8K), the **High FPS Wall
  Seam Fix**, **Bug Fix - Startup Black Screen** and the 100/120/144/240 FPS patches, merged into
  our per-title files. They are located by signature, so they also apply to other builds.
- **High FPS Physics Fix**: while a QTE prompt is on screen the engine runs at 60 FPS and returns to
  your rate afterwards. It lives in the runtime, not in a guest hook, so it works on ARM64.
- **AMD FSR upscaling and frame generation** (FSR 3.1 / 4 / 4.1, 2x frame generation) are compiled
  into the ARM64 build; **NVIDIA DLSS is gone**, as upstream removed it.
- **Launcher**: upstream 3.0.0's controller mapping page and switch-attack option, plus our own
  **save import from a zip**. Every new string is translated in all four of our languages
  (简体中文 / Bahasa Indonesia / Português / Español), patch notes included.
- **Our port's own features** are unchanged: the on-screen virtual key layout (17 controls laid out
  for a landscape phone), the in-game trophy list and fps overlay, the pause-menu "Exit to Desktop",
  and the atomic two-phase install.

### Not in the package, and why

- **The Rust launcher.** Upstream 3.0.0 moved the launcher to Rust; the ARM64 package keeps the
  Python launcher, because the runtime chain is `entry.sh → run.py → launcher`. Everything the
  Python launcher got in 3.0.0 is here; the Rust launcher's own UI work (auto GUI scale, dark
  title bar) is not.
- **In-game Options > Graphics** (Texture Quality, Shadows, Motion Blur, Bloom) and **switch
  attacks** (L1 + d-pad, L1 + Cross). Upstream implements them by writing x86-64 code into the guest
  image. Under the FEX JIT the image is translated, so they need the ARM64 rewrite we already did
  for the cheats, the QTE prompts, the enemy health bar, the multipliers and the pause menu.
- **The Cronos blade pull cap** reads Kratos' object out of the guest image (upstream's native
  player hook), same reason.
- The **wall seam fix**, on the other hand, *is* in the package: it ships as a patch (byte writes in
  the eboot), so it does not depend on the hook path.

### Known issues

- **Only Qualcomm GPUs are supported** (Adreno). Other Android GPUs are not supported yet.
- Frame generation is experimental: it needs an upscaler, and upstream still sees it inactive in
  some areas (Cronos, Realm of Hades, Hades Throne Room, The Forge, City of Olympia, The Path of
  Eos).
- Trophies are local: PlayStation unlocks are not imported.
- The Rust-launcher-only UI (auto GUI scale, dark title bar) is not part of this package.
- Upstream's own open issues still apply (infinite loading screens on some transitions, texture
  corruption on some systems, some players seeing the game run faster than its cap).

## 中文

**这一版把 ARM64 移植推进到与 PC 端功能对齐：上游 3.0.0 的东西基本都在包里，不在的那几项
都在下面写清了原因。**

### 包里有什么

- **完整合入上游 3.0.0**（489 个提交，`windows-v3.0.0` → `a2299cd`）：运行时、图形栈、补丁集与
  启动器文案。
- **补丁集**：上游改成具体尺寸的分辨率补丁（1280x800 … 8K）、**High FPS Wall Seam Fix**、
  **Bug Fix - Startup Black Screen**，以及 100/120/144/240 FPS 补丁，都并进了我们的 per-title
  补丁文件；这些条目按签名定位，换一个构建也能命中。
- **高帧率物理修复**：QTE 提示出现在屏幕上时引擎降到 60 FPS，提示结束后回到你的帧率。这一条
  实现在运行时里，不依赖 guest 钩子，ARM64 上照常生效。
- **AMD FSR 放大与帧生成**（FSR 3.1 / 4 / 4.1，2x 帧生成）已编进 ARM64 版；**NVIDIA DLSS 按上游
  的做法移除**。
- **启动器**：上游 3.0.0 的手柄映射页与换招攻击选项，加上我们自己的**从 zip 导入存档**。新增
  文案在四种语言（简体中文 / 印尼语 / 葡语 / 西语）里全部补齐，补丁说明也算在内。
- **端口自带的东西**不变：按横屏握持排布的屏上虚拟按键（17 个控件）、游戏内奖杯列表与帧率
  叠加层、暂停菜单的 “Exit to Desktop”，以及两阶段原子安装。

### 不在包里的，以及原因

- **Rust 启动器**。上游 3.0.0 把启动器换成了 Rust；ARM64 包继续用 Python 启动器，因为运行链是
  `entry.sh → run.py → launcher`。Python 启动器在 3.0.0 里拿到的东西都在；Rust 启动器独有的
  UI（自动缩放、暗色标题栏）不在。
- **游戏内 Options > Graphics**（Texture Quality、Shadows、Motion Blur、Bloom）与**换招攻击**
  （L1 + 方向键、L1 + 叉键）。上游是往 guest 镜像里写 x86-64 机器码实现的；FEX JIT 下镜像会被
  翻译，得像我们已经重做过的金手指、QTE 提示、敌血条、倍率、暂停菜单那样再做一遍 ARM64 版。
- **Cronos 拔刀限速**要从 guest 镜像里读奎托斯的对象（上游的原生 player 钩子），同理。
- 但**墙缝修复**在包里：它是以补丁（eboot 里的字节改写）形式交付的，不走钩子路径。

### 已知问题

- **目前只支持高通 GPU**（Adreno），其它 Android GPU 暂未支持。
- 帧生成仍是实验功能：需要先开放大器，且上游实测在部分区域（Cronos、冥界之域、冥界王座、
  锻造厂、奥林匹斯城、Eos 小径）不生效。
- 奖杯只存在本地：PlayStation 的解锁不会导入。
- Rust 启动器独有的 UI（自动缩放、暗色标题栏）不在本包里。
- 上游仍未关闭的问题继续存在（部分场景切换时无限读条、部分系统贴图损坏、个别玩家觉得游戏比
  上限跑得快）。
